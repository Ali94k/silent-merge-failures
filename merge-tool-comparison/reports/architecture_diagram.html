Classification Logic (comparator.py)

TP True Positive
CLEAN + output == developer resolution → correct merge
FP False Positive
CLEAN + output ≠ developer resolution → silent error
TN True Negative
CONFLICT + both sides changed, dev picked / wrote novel
FN False Negative
CONFLICT + only one side changed, or dev reverted to base → false alarm

Metrics (per tool, per category)

Precision
TP / (TP + FP)
How often a "clean" merge is actually correct.
Recall
TP / (TP + FN)
How often correct merges are produced without false conflicts.
F1 Score
2·P·R / (P + R)
Harmonic mean of precision and recall.
Incorrect Merge Rate
FP / (TP + FP)
Rate of silent wrong merges — most dangerous failure mode.
Weighted Cost
FP·10 + (FN+TN)·1 + (CRASH+TIMEOUT)·1
Schesch et al. cost model — FP weighted 10× heavier.
Avg Runtime
mean(runtime_seconds)
Mean wall-clock time per scenario.
